# v0.1 language rules

this file inventories the current v0.1 language rules. it does not repair,
reinterpret or extend them. if the language references a thing without defining
enough of it to implement, that thing goes into
[`implementation-blockers.md`](implementation-blockers.md). the compiler does
not get custody of language design merely because it has a parser nearby.

## id rules

- `SNN` identifies a top-level language section.
- `SNN-NAME` identifies one normative rule family under that section.
- prose, lists, tables and examples under a heading belong to that heading's
  audit ID until the next heading.
- example IDs are assigned separately in
  [`conformance-index.md`](conformance-index.md).
- these IDs are stable language-rule anchors.

## audit result

all 13 language areas and their current rule families have an audit ID.
the inventory deliberately does not claim that every referenced syntax form is
implementable. those gaps are listed separately, because a missing grammar rule
does not become real through confidence theatre.
